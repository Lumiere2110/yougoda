# 用語打（yougo-da）

数学・物理・化学・生物・地学・法学・情報の学術用語、日常の言葉、英語で鍛える、タイピング練習アプリです。AIコーチが苦手なキー・文字・よく間違える問題を記録し、あなた専用の練習問題を作ります。

**プレイ:** https://lumiere2110.github.io/yougoda/

## 特徴

- **ステージ（科目）:** 日常・数学・物理・化学・生物・地学・法学・情報・英語・総合。科目ごとにカテゴリを複数選択できます（全36カテゴリ、2351問）。
- **日常:** あいさつ・会話／食べ物・料理／家・生活／買い物・まち／学校・仕事／趣味・季節の6カテゴリ（515問）。
- **英語:** TOEIC・日常会話・情報（プログラミングのコードを含む）の3カテゴリ。英文をそのまま打ちます（スペース・記号も入力、大文字小文字は区別なし）。日本語訳も表示されます。レベルは英字2文字をかな1字として数えます。
- **レベル:** 読みの文字数で出題を絞ります。Lv.1 は 3〜6 字、Lv.2 は 5〜10 字、Lv.3 は 7〜16 字、Lv.4 は 12〜24 字。
- **出題順:** 最初は短い問題から始まり、時間が進むにつれてだんだん長い問題が出ます（AIの練習問題も短い順）。
- **プレイ時間:** 1〜5 分。
- **1問ごとの制限時間:** 無制限・ゆっくり・ふつう・はやい・鬼・カスタム。
- **ルール:** ノーマル／一発勝負（ミスでその問題は不正解）／サドンデス（1ミスで終了）。
- **表示:** ひらがな・漢字かな・カタカナ・ローマ字をそれぞれ切り替え可能。
- **入力方法:** ローマ字（複数の表記に対応: shi/si/ci、っ→kk/xtu など）と、かな（フリック入力）を選べます。漢字変換が必要な問題は出ません。

## 検定テスト（100点満点）

設定画面の「検定テスト」から始めます。タイピング技能検定（イータイピング・マスター）の形式を参考にした、単語・短文・長文の3科目のテストです。

- 各科目60秒。時間内にできるだけ速く正確に打ちます（ミスしても打ち直せます）。
- ポイント = 正しく打った数 × 60 ÷ 秒 × 正確率²。正確率が2乗で効くので、ミスは大きく減点されます。
- 同検定の**特級の合格スコア（単語 360・短文 420・長文 450）に届くと、その科目は100点**です。3科目の平均が得点になります（3科目とも100点で特級合格レベル）。
- 出題は設定画面の科目・カテゴリ・レベルに関係なく、全科目（日本語・英語）から長さで選びます。検定の基準がローマ字の打鍵数なので、テストはローマ字入力で行います。
- 結果画面では科目ごとの得点・ポイントと、特級に必要な速さ、正確率を上げたときの伸びしろを表示します。

本アプリは同検定とは関係がなく、得点は練習用の目安です。

## 目標点数と平均との比較

結果画面の「くらべる」で、今回の点数を次と比べられます。

- **目標:** 設定画面（通常プレイは条件ごと）や検定テストの案内画面、結果画面で目標点数を入れておくと、「目標まであと◯点」「目標達成」を表示します。
- **あなたの平均:** 同じ条件でのこれまでの平均点（この端末に保存）。
- **みんなの平均:** オンラインランキングに登録された点数の平均。オンラインランキング（Firebase）を設定すると表示されます。
- **参考（全国）:** 1分あたりの入力文字数と、高校生の全国平均 24.7 字/分（文部科学省 2017年度 情報活用能力調査）を並べて表示します。調査は漢字かな交じり文を変換しながら入力した文字数、このアプリは読みのかな・英字の数なので、目安として見てください。

## ランキングと日ごとの記録

画面右上の「ランキング」から開きます。

- **通常プレイ:** 科目・レベル・プレイ時間・制限時間・ルール・入力方法がすべて同じ条件どうしでランキングします。
- **検定テスト:** 全科目から出題されるので、ランキングは1つです。
- **この端末:** 条件ごとに上位10件をブラウザに保存します。名前を入れておくと、家族や友達と同じ端末で競えます。
- **みんな（オンライン）:** 下の「オンラインランキングの設定」をすると、結果画面の「みんなのランキングに登録」で登録でき、上位20件が表示されます。
- **日ごとの記録:** 日ごとの最高速度・その時の正確率・検定テストの最高点・回数・打った数を記録し、グラフと表で上達の推移を表示します。結果画面では「今日の最高速度を更新」「これまでの最高速度を更新！」などをお知らせします。

### オンラインランキングの設定（Firebase）

オンラインランキングには Google の Firebase（Cloud Firestore、無料枠で使えます）を使います。設定するまでは「この端末」のランキングだけが表示されます。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成する
2. 「Firestore Database」を作成する（本番環境モード、ロケーションは asia-northeast1 など）
3. 「ルール」タブに次を貼り付けて公開する
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /boards/{board}/scores/{id} {
         allow read: if true;
         allow create: if request.resource.data.keys().hasOnly(['name','score','kps','acc','t'])
           && request.resource.data.name is string
           && request.resource.data.name.size() >= 1 && request.resource.data.name.size() <= 12
           && request.resource.data.score is number && request.resource.data.score >= 0
           && request.resource.data.score <= (board.matches('test-.*') ? 100 : 50000)
           && request.resource.data.kps is number && request.resource.data.kps >= 0 && request.resource.data.kps <= 20
           && request.resource.data.acc is number && request.resource.data.acc >= 0 && request.resource.data.acc <= 1
           && request.resource.data.t is int;
         allow update, delete: if false;
       }
     }
   }
   ```
4. 「プロジェクトの設定」→「マイアプリ」でウェブアプリを追加し、表示される `projectId` と `apiKey` を `index.html` の `RANKING_CONFIG` に書く
   ```js
   const RANKING_CONFIG={projectId:'your-project-id',apiKey:'AIza...'};
   ```

Firebase のウェブ用 API キーは公開して使う前提の値で、書き込める内容は上のルールで制限しています。ただしブラウザから直接送る仕組みなので、不正なスコアの送信を完全には防げません。ルールでは、あり得ない値（毎秒20打を超える速度、検定テストで100点超えなど）を拒否しています。

## AIコーチ

画面右上の「AIコーチ」から開きます。プレイ・練習のたびに、次の内容をブラウザ（localStorage）に自動で記録します。外部サーバーには送信しません。

- **苦手なキー:** キーごとのミス率、担当の指、よく打ち間違える別のキー（例: j を k と打つ）
- **苦手な文字:** かな単位（し・っ・ん・しゃ など）のミス回数と、別の打ち方のヒント（si / ti / nn / xtu など）
- **入力に時間がかかるキー・文字:** 1つ前の正しい打鍵から次のキーを押すまでの時間を記録し、全体の平均と比べて遅い（迷っている）キーや文字を見つけます。2.5秒を超える間隔は手が止まっていたとみなして集計しません。ローマ字入力のときだけ記録します。
- **打ち始めに時間がかかる問題:** 問題が出てから最初のキーを押すまでの時間が、全体の平均より目立って長い問題（読み方を思い出すのに迷っている問題）を見つけ、練習問題で復習させます。
- **よく間違える問題:** ミスや時間切れがあった問題。3回連続ノーミスで「克服」になります
- **成長の推移:** 直近の速度・正確率を以前と比べてコメントします

記録をもとに、**練習問題を自動で作成**できます（10・20・30問）。

- **おまかせ（AIミックス）:** 間違えた問題の復習＋苦手な文字・キーを含む用語
- **間違えた問題の復習:** つまずいた問題だけを出題
- **苦手文字ドリル:** 苦手な文字を多く含む練習用の文字列と、その文字を含む用語
- **苦手キー特訓:** 苦手なキーを何度も打つ、かなの練習用文字列

結果画面には今回のミスの分析が表示され、「AIの練習問題で復習」からすぐに練習を始められます。分析はブラウザ内で動く仕組みで、外部の生成AIは使っていません。

## スコア

- 1打ごと: 1〜6点（レベル + 連続入力 30 打以上で +1、60 打以上で +2）
- 1問クリア: 10〜23点（レベル別の基本点 + ノーミスで +4）
- 連続入力ボーナス: ミスなし 30 打ごとに +10 → +15 → +20 → +25（最大 4 回、ミスでリセット）

## 遊び方

`index.html` をブラウザで開くだけで動きます。最初にタイトル画面が出ます。

- **プレイ:** 科目・レベルなどを選んで練習します（これまでどおり）。
- **テスト:** 検定テスト（100点満点）を受けます。
- **設定:** 効果音（ON/OFF・音量）、カラー（テーマ: 自動／ライト／ダーク、アクセント: 藍・翠・紫・橙）、表示する文字、目標点数を設定します。設定はブラウザに保存されます。
- **終了:** ページを閉じます。ブラウザはスクリプトで開いたタブや履歴が1ページだけのタブしか閉じさせないため、閉じられないときは「タブを閉じてください」と案内します。
- タイトル画面では 1〜4 のキーや ↑↓ キーでも選べます。画面左上のロゴを押すとタイトルに戻ります。

- **パソコン:** Enter で開始、Esc で中断。日本語入力（IME）はオフにしてください。
- **フリック入力:** 設定の「入力方法」で「かな」を選ぶと、スマホの12キーと同じフリックキーボードでかなを直接入力できます。濁点・半濁点・小さい文字は「゛゜小」キーで付けます。次に打つキーとフリックの方向が光ります。英数字を含む問題と英語は出題されません。
- **スマホ・タブレット:** 画面下に専用キーボードが出ます。次に打つキーが青く光り、記号が必要なときは記号の面に自動で切り替わります。プレイ中の「画面キーボード」ボタンで表示を切り替えられます（Bluetooth キーボードも使えます）。
